2. Deep Concept Breakdown

A. Taylor and Maclaurin Series Definition

A Taylor series represents a smooth function $f(x)$ as an infinite polynomial centered at a point $x = c$. If $c = 0$, the series is specifically termed a Maclaurin series.

$$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(c)}{n!} (x - c)^n = f(c) + f'(c)(x-c) + \frac{f''(c)}{2!}(x-c)^2 + \frac{f'''(c)}{3!}(x-c)^3 + \dots$$

The $N$-th degree Taylor Polynomial, denoted $P_N(x)$, truncates the infinite series at $n = N$:

$$P_N(x) = \sum_{n=0}^{N} \frac{f^{(n)}(c)}{n!} (x - c)^n$$

Four Essential Maclaurin Series to Memorize

$$\begin{aligned} \frac{1}{1-x} &= \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \dots \quad (|x| < 1) \ e^x &= \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots \quad (-\infty < x < \infty) \ \sin x &= \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots \quad (-\infty < x < \infty) \ \cos x &= \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots \quad (-\infty < x < \infty) \end{aligned}$$

B. The Remainder Theorem & Lagrange Error Bound

When approximating $f(x)$ using $P_N(x)$, an error exists. This difference is defined as the remainder $R_N(x)$:

$$f(x) = P_N(x) + R_N(x) \implies R_N(x) = f(x) - P_N(x)$$

The Lagrange Error Bound places a strict mathematical ceiling on the magnitude of this remainder:

$$|R_N(x)| = |f(x) - P_N(x)| \le \frac{M}{(N+1)!} |x - c|^{N+1}$$

Where: * $N$ is the degree of the approximating Taylor polynomial. * $c$ is the center of the Taylor polynomial. * $x$ is the evaluation point. * $M$ is an upper bound on the absolute value of the $(N+1)$-th derivative of $f$ on the interval between $c$ and $x$. That is:

$$M \ge \max_{z \in [c, x]} \left| f^{(N+1)}(z) \right|$$

Conceptual Intuition for $M$

The Lagrange Error Bound resembles the next term in the Taylor expansion, $\frac{f^{(N+1)}(c)}{(N+1)!}(x-c)^{N+1}$, except that $f^{(N+1)}(c)$ is replaced by $M$—the worst-case (maximum possible) magnitude of the $(N+1)$-th derivative anywhere on the closed interval between the center $c$ and the evaluation point $x$.

C. Lagrange vs. Alternating Series Error Bound

A frequent area of confusion is selecting the correct bound method:

Feature Alternating Series Error Bound Lagrange Error Bound
Prerequisites Series must strictly alternate, terms must decrease in magnitude, $\lim_{n\to\infty} a_n = 0$. Function $f$ must be $(N+1)$ times differentiable on the interval $[c, x]$.
Bound Formula $ R_N
When to Use Explicit numerical alternating series with known terms. Non-alternating series, or when given explicit derivative bounds or graphs of $f^{(N+1)}(x)$.

Critical Rubric Nuances

  1. Explicit Inequality Writing: Always explicitly link $f(x)$ and $P_N(x)$ in your final line. Simply calculating a number like $0.0032$ is insufficient. You must write: $$|f(1.2) - P_3(1.2)| \le 0.0032$$
  2. Identifying $M$ correctly: If the problem provides a graph or table of $f^{(N+1)}(x)$, locate the absolute maximum of the graph on $[c, x]$. Do not simply pick $f^{(N+1)}(c)$ or $f^{(N+1)}(x)$ unless that point is guaranteed to be the maximum.
  3. Degree vs. Index: If a polynomial has zero-coefficient terms (e.g., $P_4(x) = 1 - \frac{x^2}{2!} + \frac{x^4}{4!}$ for $\cos x$), notice that $P_4(x)$ is a $4\text{th}$-degree polynomial. The next non-zero term uses $N+1 = 5$ or $N+1 = 6$ depending on how the problem specifies the order. Always check whether the problem asks for degree $N$ or $N$ non-zero terms.

5. Practice Problem & Strategy Summary

High-Yield AP-Style Free Response Question

Let $f$ be a function that has derivatives of all orders for all real numbers. It is known that: * $f(1) = 2$ * $f'(1) = -3$ * $f''(1) = 6$ * $f'''(1) = 12$

The fourth derivative of $f$ satisfies the inequality $|f^{(4)}(x)| \le 48$ for all $x$ in the closed interval $[1, 1.2]$.

(a) Write the third-degree Taylor polynomial $P_3(x)$ for $f$ about $c = 1$.
(b) Use $P_3(1.2)$ to approximate $f(1.2)$.
(c) Use the Lagrange Error Bound to show that $|f(1.2) - P_3(1.2)| \le 0.0032$.
(d) Determine if $f(1.2)$ could equal $1.54$. Justify your answer using your results from parts (b) and (c).

Step-by-Step Solution

Part (a)

The third-degree Taylor polynomial centered at $c = 1$ is: $$P_3(x) = f(1) + f'(1)(x-1) + \frac{f''(1)}{2!}(x-1)^2 + \frac{f'''(1)}{3!}(x-1)^3$$

Substitute the given derivative values: $$P_3(x) = 2 + (-3)(x-1) + \frac{6}{2}(x-1)^2 + \frac{12}{6}(x-1)^3$$ $$P_3(x) = 2 - 3(x-1) + 3(x-1)^2 + 2(x-1)^3$$

Part (b)

Evaluate $P_3(x)$ at $x = 1.2$: $$\begin{aligned} P_3(1.2) &= 2 - 3(1.2 - 1) + 3(1.2 - 1)^2 + 2(1.2 - 1)^3 \ &= 2 - 3(0.2) + 3(0.2)^2 + 2(0.2)^3 \ &= 2 - 0.6 + 3(0.04) + 2(0.008) \ &= 1.4 + 0.12 + 0.016 \ &= 1.536 \end{aligned}$$

Thus, $f(1.2) \approx 1.536$.

Part (c)

By the Lagrange Error Bound: $$|R_3(1.2)| = |f(1.2) - P_3(1.2)| \le \frac{M}{(3+1)!} |1.2 - 1|^{3+1} = \frac{M}{4!} (0.2)^4$$

We are given that $M = \max_{x \in [1, 1.2]} |f^{(4)}(x)| \le 48$.

Substituting $M = 48$: $$|f(1.2) - P_3(1.2)| \le \frac{48}{24} (0.2)^4 = 2 \cdot (0.0016) = 0.0032$$

$$\therefore |f(1.2) - P_3(1.2)| \le 0.0032$$

Part (d)

From parts (b) and (c), we know: $$P_3(1.2) - 0.0032 \le f(1.2) \le P_3(1.2) + 0.0032$$ $$1.536 - 0.0032 \le f(1.2) \le 1.536 + 0.0032$$ $$1.5328 \le f(1.2) \le 1.5392$$

Since $1.54 > 1.5392$, $1.54$ lies strictly outside the interval of possible values for $f(1.2)$. Therefore, $f(1.2)$ cannot equal $1.54$.

6. Score 5 Checklist for Exam Day

When encountering a Taylor Series / Error Bound question on the exam:

  • [ ] Identify the center $c$ and target evaluation point $x$.
  • [ ] Verify if the series is alternating. If alternating and terms decrease to 0, consider using the Alternating Series Bound $|R_N| \le |a_{N+1}|$.
  • [ ] For Lagrange bounds, set up the $(N+1)$-th derivative condition clearly.
  • [ ] Find $M$ explicitly. Ensure $M$ is the upper bound on $[c, x]$, not just at a single point.
  • [ ] Write the final error bound statement as an absolute inequality: $$|f(x) - P_N(x)| \le \text{Calculated Bound}$$
  • [ ] Double-check simple arithmetic, especially powers of decimals like $(0.1)^3$ or $(0.2)^4$.
